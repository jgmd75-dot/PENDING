GFX - PENDING
=============

Finished GFX plug-ins waiting to join GFX-II and the website (gardenfx.uk).
They are released in groups, so that every website category keeps a multiple
of three plug-ins. They need the GFX system files (.jsfx-inc) in the same
folder, as usual.

  TRDI            gfx-trdi.jsfx            Utilities       transformer DI
  ALIGN           gfx-align.jsfx           Utilities       phase / time alignment
  CHECK           gfx-check.jsfx           Utilities       mix-translation monitor controller
  SHK34           gfx-shk34.jsfx           Drums           shakers + tambourine, step sequencer
  BEL34           gfx-bel34.jsfx           Drums           cowbell + triangle, step sequencer
  CLV34           gfx-clv34.jsfx           Drums           clave, woodblocks + agogo, step sequencer
  BED34           gfx-bed34.jsfx           Amps & drive    practice amps (3 models x 3 speakers) + broken speaker
  FYRE            gfx-fyre.jsfx            Amps & drive    boost / treble booster / fuzz rack
  MSAT            gfx-msat.jsfx            Mastering       3-band saturation, transients, width, solo / mute
  CH34            gfx-ch34.jsfx            Dynamics        preamp + drive / parametric EQ / VCA comp strip, EQ-comp swap
  SUP34           gfx-sup34.jsfx           Dynamics        console strip: VHD preamp, filters, comp, gate, E/G EQ, routing
  GLU34           gfx-glu34.jsfx           Dynamics        stereo bus compressor: stepped controls, auto release, VCA drive, SC HPF, ext key
  BOB34           gfx-bob34.jsfx           Modulation      modular rack: ladder LP, ring mod, phaser, filter array, saturator + CV
  COM34           gfx-com34.jsfx           Mastering       stepped diode-bridge compressor: auto ratio, soft, bass, link
  BUS34           gfx-bus34.jsfx           Mastering       stereo colour unit: drive, shelves, HF comp, image, transformer
  KBH77           gfx-kbh77.jsfx           Dynamics        broadcast strip: 18 dB/oct filters, presence EQ, comp / exp + hold + gate, log-clip limiter
  PRE3            gfx-pre3.jsfx            Amps & drive    preamp: WEST / JH / AERO models, one face each, neutral at DRIVE 0
